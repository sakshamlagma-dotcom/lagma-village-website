# Security Policy

## Supported Versions
We provide security updates for the following versions:

| Version | Supported |
|---------|-----------|
| 5.1.x   | ✅ |
| 4.0.x   | ✅ |
| < 4.0   | ❌ |

## Reporting a Vulnerability
If you discover a security issue, please report it responsibly:

- **Email:** sakshamlagma@gmail.com  
- **GitHub Issues:** [Open a security issue](https://github.com/lagma-village-website/issues) 
- **Response Time:** We aim to respond within **72 hours**.  
- **Disclosure:** Please do not publicly disclose the vulnerability until it has been fixed.

## Guidelines
- Provide clear steps to reproduce the issue.  
- Mention affected versions and environment details.  
- Suggest possible fixes if available.  
- Follow responsible disclosure practices.
